Install thousand

Hello, welcome to the first lesson about the thousand.js library.
Today we will learn how to install the library using imports. Let's look at the first code.

For the first code, we'll add an import,
and then we'll put its version in from.

import TH from "https://cdn.jsdelivr.net/gh/thousandjs/thousand.js@<version>/build/thousand.module.js"

The code above works without installation, but if you want to use the local installation module
you should use other types, which is the best option.
However, if you don't want to, then use the non-recommended option:

<script src="https://cdn.jsdelivr.net/gh/thousandjs/thousand.js@<version>/build/thousand.module.js">

After that, our library is already imported.
If you want, let's learn more about thousand.js in Create a scene

If you want simplicity and not too many things getting in the way, follow the example below: Place the tag below in your head code.


<script type="importmap">
  {
   "imports": {
     "thousand": "https://cdn.jsdelivr.net/gh/thousandjs/thousand.js@<version>/build/thousand.module.js",
     "thousand/addons": "https://cdn.jsdelivr/gh/thousandjs/thousand.js@<version>/addons/"
    }
  }
</script>

NOTE:


The code above requires option 2 plus `from`:
with the URL `thousand` (it doesn't require https:// because it's already defined in the importmap).
