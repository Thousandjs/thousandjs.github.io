Now that we've installed the library, how about implementing it?

To begin, let's talk about the topic:

A scene is essential to the start of construction;
to begin, we have to render it in our project/application to start building.
So, since we know the principle, we can start getting our hands dirty with the project.

Starting with the creation of essential variables:


const scene = TH.scene(); // Export the scene. Don't forget to `import TH from "thousand"`

const rendering = TH.rendering(document.body) // Essential for rendering. We typically use document.body or another element.



Create a cube

Now that we can put this into practice, let's bring our scene to life. How about adding a cube?
Before we get into that topic, let's look at it a little beforehand.

Cubes in `thousand.js` are part of the rectangle family, which is a simple way to add rectangles.
Cubes, however, are not recommended for simple graphics, but rather for images.

If you've already accessed the homepage, you must have seen some cubes with images.
Forget about 3D and see 2D; cubes are mostly images and heavier for super rectangles.
But now that we know the difference between rectangles and cubes in `thousand.js`

let's look at their arguments:


// rectangles (todays)
TH.create.rect( x, y, w, h );

// cubes (now)
TH.create.cube(info); // info = { map: map, mesh: mesh }

// cube infos
const map = {

Arguments and indentation:

Scene


scene.background( r, g, b );

`scene.background();` is used to easily color the screen.


scene.add( element );

`scene.add();` is used to add elements, is not mandatory.

scene.remove( element );

`scene.remove();` is used to remove elements from the scene.

`scene.save();` & `scene.load();` and `scene.restore();`

`scene.save();` and `scene.load();` are used to reload past times where `save` was executed (restore has the same function as load).

Rendering

Rendering contains HTMLCanvasElement elements.
